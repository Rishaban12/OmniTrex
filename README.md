# OmniTrex

**Connect. Create. Grow.** Three everyday tools in one offline Android app, built with Flutter.

- **DoList:** to-dos with start and end dates and times, plus a home-screen widget you can tick off.
- **PocketPlan:** a daily budget that works out what you can spend today, with bank SMS and UPI tracking, insights, and reminders and alerts.
- **MindNotes:** quick notes you can search, pin and colour.

No account and no internet needed: everything is stored on your device.

## Download

Get the latest APK from the [Releases](https://github.com/Rishaban12/OmniTrex/releases) page and install it on your Android phone (allow "install unknown apps" when asked).

## Build from source

```
flutter pub get
flutter run --release
```

Tests: `flutter test`

Built with Flutter, Riverpod, Drift (SQLite) and Material 3.
